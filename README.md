# SQL + Power BI Employee Dashboard

This is an end-to-end data analytics project where SQL is used for data extraction
and Power BI is used for creating interactive dashboards.

## Tools Used
- MySQL
- SQL
- Power BI

## Project Workflow
1. Employee data stored in SQL database
2. SQL queries used for data analysis
3. Power BI connected to SQL database
4. Dashboard created for insights

## Project Structure
- SQL/employee_analysis.sql
- PowerBI/Employee_Dashboard.pbix
- PowerBI/dashboard.png

## Key Insights
- Department-wise salary analysis
- Highest and lowest paid employees
- Employee distribution across departments
